세이프픽스 — Google AI Studio 원본 디자인 적용본

실행: npm install → npm run dev
빌드: npm run build
빌드 미리보기: npm run preview

원본 디자인에서 유지한 요소
- 폰트 및 민트/에메랄드 컬러, 큰 제목과 히어로 배치
- 둥근 버튼, 말풍선 소개, 진행 카드와 움직이는 연결선
- 서비스 카드, FAQ 드롭다운/아코디언, 카드 hover 효과
- 헤더 및 어두운 4열 푸터의 시각적 구성

적용한 구조
히어로 → 진행 과정 → 회사소개 → 서비스 약속 → 지원 기기 → 기업·기관 → 수리 서비스 → 후기 영역 → 방문/접수 안내 → FAQ → 상담 CTA

범위
메인 홈페이지를 세이프픽스의 Apple 기기 수리업 콘텐츠로 변경했습니다.
서비스 상세 안내와 상담 메모 화면을 연결했습니다.
기존 청소업 관리자, 인증, Firebase 및 외부 문의 전송 코드는 포함하지 않습니다.
상담 폼은 접수되지 않으며 이 화면에서만 상담 내용을 정리/복사합니다.
연락처·주소·운영시간·보증 기간은 미정으로 두었습니다.
실제 후기가 제공되지 않아 임의 후기는 작성하지 않았습니다.

이미지
원본 ZIP의 WebP 15개가 정상 디코딩되지 않았습니다.
배경은 같은 ZIP에 포함된 정상 JPG를 사용했습니다.
수리 안내 사진은 요청하신 ipadrepair.co.kr 메인 페이지에서 가져온 참고 이미지입니다.
따라서 손상된 이미지와 업종 관련 사진까지 픽셀 단위로 동일한 결과는 아닙니다.

주요 파일
pages/Home.tsx: 원본 스타일을 유지한 메인 구성
constants.ts: 상호, 사업장 정보, 수리 서비스
components/Navbar.tsx / Footer.tsx: 메뉴 및 푸터
App.tsx: 화면 연결, 서비스 상세, 상담 메모
tailwind.config.cjs: 원본 테마

검증: Vite 빌드, TypeScript, PC/390px 모바일 레이아웃 및 메뉴 확인.

2026-10-16 색상 업데이트: 화이트·쿨그레이·차콜 바탕, #0071E3 블루 강조. 기존 배치와 효과를 유지하고 히어로 사진은 CSS로 무채색 처리했습니다.
